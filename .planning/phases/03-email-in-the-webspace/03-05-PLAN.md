<objective>
Close the one confirmed code-level BLOCKER from 03-VERIFICATION.md: `plugins/proton/plugin.go` fetches every message's IMAP INTERNALDATE (`imap.FetchInternalDate`, plugin.go:151) but has no field on the per-message `matched` struct to hold it, so the value is discarded and `toItem()` never sets `Item.TimestampUnix`. This plan fixes the code and installs the assertion that makes this class of silent field-drop impossible to repeat.
