<objective>
Land UI-07: the webspace header presents each source instance exactly once, as one affordance combining health, filter toggle and refresh, and stays usable as the instance count grows.

This replaces two header rows (`SourceHealthChip` + `SourceFilterChips`) with one `SourceChip` per instance, promotes the single-select source filter to a multi-select set persisted in the URL, and keeps the row on a single line at any instance count by measuring available width and moving the remainder into an overflow popover.

Purpose: close success criterion 1 against Phase 5's final source-identity model.
Output: a merged chip component, a shadcn-style popover wrapper over the already-installed bits-ui primitive, Set-based filter helpers, and the retirement of both old chip components.
</objective>

`visibleChipCount(chipWidths: number[], availableWidth: number, reservedWidth: number, overflowTriggerWidth: number): number` returns how many chips fit inline. Migrate every existing assertion in `sources.test.ts` to the new set-based signatures rather than deleting it, then add the new coverage. Keep the existing fixture-factory convention.

Cover, at minimum:
- **Per-member degrade.** A query value naming one configured and one removed instance resolves to a one-member set holding only the configured name. A value naming only removed instances resolves to the empty set, which means show everything, never an error and never an empty stream. A null, empty and whitespace-only value each resolve to the empty set. Extra commas and surrounding whitespace around members are tolerated.
- **Round trip.** Serializing a resolved set and re-resolving it yields an equal set.
- **Toggle idempotency.** Toggling a name twice returns a set equal to the original, and the input set is never mutated.
- **Filtering.** An empty set returns every item in unchanged order. A two-member set returns exactly the items from those two sources, in the response's original order — no sort and no regroup.
- **Stream variant precedence.** A response whose sync failed with zero items resolves to the sync-failed variant whether the set is empty or populated — a filter can never mask a sync failure.
