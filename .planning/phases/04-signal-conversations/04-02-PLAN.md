rather than by convention, complete key resolution so the plugin works on a
safeStorage-migrated install and not only on this machine's legacy one, and make every

future edit that reintroduces a write path, an assumed keyring backend, or a silent
schema skip fails the build instead of the user's database.

enforced by tests, and whose three failure modes are legible in the UI.

**safestorage_linux.go.** Implement the Electron/Chromium `os_crypt` unwrap using Go
stdlib `crypto/aes` and `crypto/cipher` plus `golang.org/x/crypto/pbkdf2`. The constants
are Chromium's own and are load-bearing: the PBKDF2 salt is the literal string
`saltysalt`, the iteration count is 1, the derived key length is 16 bytes, the hash is
SHA-1, and the IV is 16 repetitions of the space character (0x20) rather than a random
value. Declare each as a named constant with a comment stating it is copied verbatim from
the documented scheme and must not be "simplified" — a wrong constant produces silent
garbage rather than an error, because CBC has no integrity check. Strip the three-byte
`v10` or `v11` prefix, reject a blob carrying neither, reject a ciphertext whose length is
not a multiple of the block size, decrypt, then strip PKCS7 padding and reject a malformed
padding result loudly. Do not import a third-party "Electron safeStorage in Go" package —
the algorithm is small enough that a wrapper adds trust surface without adding safety.

**secretservice.go.** Wrap `github.com/keybase/go-keychain/secretservice` to fetch the
safeStorage master password from `org.freedesktop.secrets`. Use its encrypted session mode
(`AuthenticationDHAES`) — never the plain session mode, which would carry the secret over
the session bus in the clear. Open a session, resolve the default collection, unlock it if
locked, search by the attribute Electron stores the entry under for the backend named in
`config.json`, and return the secret. Do not hand-roll the Diffie-Hellman handshake. Every
error returned from this file names the failing D-Bus step and the backend, never a
secret. If `org.freedesktop.secrets` is not present on the session bus, return an error
saying so by name, since that is a real and common state on a desktop environment outside
Electron's own backend allowlist.

**keyresolve.go.** Complete the branch. The `encryptedKey` arm dispatches strictly on the
