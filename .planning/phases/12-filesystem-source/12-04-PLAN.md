<objective>
Give the user the front door: the filesystem plugin type appears in the picker with a connection
form that asks for a folder and whether to include its subfolders, and saving it produces a
working source. This is where success criterion 1 becomes true end to end.

Purpose: everything behind the form already works after plans 01–03. What is missing is the one
new field kind the design system does not yet have — a checkbox — and the plugin's own row in
the static connection-field table. Both are specified in full by 12-UI-SPEC.md F1, including the
deliberate absence of a default path value.

Output: the shadcn-svelte Checkbox primitive, the reusable `kind`/`helperText` extension to
`ConnectionField`, the `topos-plugin-filesystem` row, the ConnectionForm render branch, and a
browser spec that adds a folder source through the real UI.

The extras glob overrides need no row here at all: the plugin declares `include_glob` and
`exclude_glob` through its own Describe response, and Phase 11's already-shipped declared-fields
editor renders them generically.
</objective>
