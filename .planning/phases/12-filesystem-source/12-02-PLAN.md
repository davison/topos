extension allowlist the operator can widen or narrow with per-instance globs, and four honest

for paperless-ngx and must work here through the same pipeline, not as future work).

branches, and the one-line kernel MIME-allowlist gap 12-RESEARCH.md found by reading
`allowedRenditionTypes` directly.

12-CONTEXT.md and is explicitly not in scope; office formats get metadata and a deep link.

    scope_test.go, written before scope.go:
    - With no extras at all, a file is included if and only if its extension is in the default
      allowlist.
    - A non-empty `include_glob` replaces the extension test entirely: a file matching any of its
      comma-separated patterns is included even when its extension is unknown, and a file
      matching none is excluded even when its extension is in the allowlist.
    - `exclude_glob` is applied before `include_glob` and before the allowlist: a file matching
      any exclude pattern is never included, whatever else matches it.
    - Patterns are matched against the file's forward-slash path relative to the source root, so
      an arbitrary-depth pattern under a nested directory matches while the same pattern anchored
      elsewhere does not.
    - Comma-separated pattern lists tolerate surrounding whitespace and empty segments.
    - A file included by glob whose extension is unknown gets the metadata-only preview kind —
      never a guessed mime type.
    - A malformed glob pattern is reported as a named error rather than silently matching
      everything or nothing.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| source folder → plugin | Arbitrary operator-owned file content, including hostile-by-accident documents, crosses into the plugin's readers |
| plugin → kernel rendition boundary | Plugin-declared MIME type and content shape decide which kernel sanitize/wrap policy runs |
| kernel → browser | Source-controlled bytes served from the kernel's own origin |
| operator config (extras) → plugin | Glob strings the kernel deliberately never interprets |
