<objective>
Make the stream legible. The tracer proved documents reach the browser; this plan turns a bare list into the row and state design the UI contract specifies — thumbnail, title, date, tag pills and clamped preview snippet, with every empty, loading, error, partial and overflow state rendered explicitly rather than falling through to a blank region.

Purpose: the phase's core value is that a user opens one webspace and immediately groks what is there. A row that shows only a title, or an empty region where a failed sync should be explained, defeats that — and a silently under-reported webspace is the single worst failure mode this product has.

Output: the full stream surface of `01-UI-SPEC.md`, including the sync-failure state that keeps an errored sync from masquerading as an empty topic.
</objective>

**Stream response consumed by this plan:**

```ts
type SyncStatus = { status: 'ok' | 'error' | 'running'; finished_unix: number; error: string };

type StreamItem = {
  id: string;                        // "paperless:42"
  source_type: string;               // "paperless"
  source_id: string;
  title: string;
  preview: string;                   // <= 500 runes, may be ""
  timestamp_unix: number;            // paperless `created`, midnight UTC
  secondary_timestamp_unix: number;  // paperless `added`, full datetime
  labels: string[];                  // paperless tag names
  group_id: string; group_label: string;
  link: { url: string; fidelity: 'exact' | 'anchored' | 'conversation-only' };
  thumbnail_url: string;             // "/api/items/paperless:42/thumbnail"
  provenance: Record<string, string>;
};

type StreamResponse = {
  schema_version: 1;
  webspace: string;
  sync: SyncStatus;
  items: StreamItem[];
};
```

Items arrive already sorted `timestamp_unix DESC, secondary_timestamp_unix DESC, id ASC`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stream JSON → DOM | Source-controlled document titles, OCR snippets and paperless tag names rendered into the stream list. |
| kernel thumbnail route → `img` element | Source-controlled image bytes loaded into the page. |
| `sync.error` string → DOM | A failure message whose text may include host names or upstream error text. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-16 | Elevation of Privilege | source-controlled title / snippet / tag names rendered in `StreamRow.svelte` | high | mitigate | Svelte escapes interpolated text; `{@html}` is absent and asserted so by an acceptance criterion. Tag names render as `Badge` text content, never as attributes or URLs. |
| T-01-17 | Information Disclosure | `sync.error` rendered in the stream-failure state | medium | mitigate | The kernel records only the failure class plus host and status; the plugin never puts a token or `Authorization` header into an error string (T-01-02, plan 01-01). The rendered value is escaped text. |
| T-01-18 | Elevation of Privilege | thumbnail bytes loaded into an `img` | low | mitigate | Served by the kernel's own thumbnail route under the plan 01-02 MIME allowlist, `nosniff` and sandboxing CSP; rendered as an image element only, never as an embed or object. |
| T-01-19 | Denial of Service | an unbounded stream list degrading the browser | low | accept | Personal-scale document counts; constant row height keeps layout cost linear. Virtualization is explicitly deferred (UI-SPEC zero-one-many row) until real volume demands it. |
| T-01-SC | Tampering | dependency installs during this plan | high | mitigate | No new dependency is introduced — every shadcn-svelte component and `lucide-svelte` was added and audited in plan 01-01 against the `01-RESEARCH.md` Package Legitimacy Audit. Any new install requires re-running that gate first. |
</threat_model>
