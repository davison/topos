<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry → web build | `npm run build` executes committed dependency code; any new install would introduce unaudited third-party code into the shipped SPA |
| build output → go:embed → browser | Whatever Vite writes to kernel/webui/build is embedded verbatim in the kernel binary and served to the browser |
| local shell env (.env) → build/run commands | PAPERLESS_TOKEN is present in the environment of the sync/serve/smoke commands this plan runs |
| stale local process → verification signal | An old `webspaces serve` on 127.0.0.1:7777 can answer this plan's own verification probes |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-05-01 | Tampering | verification signal (stale listener on :7777) | medium | mitigate | Task 2 Edit A aborts the smoke test when the port is already occupied; Task 3 carries a precondition to check `ss -ltn 'sport = :7777'` and stop any listener before serving |
| T-01-05-02 | Information disclosure | PAPERLESS_TOKEN in command environment | high | mitigate | Env-dependent commands are confined to `bash -c` wrappers that source ./.env (gitignored); no task echoes, greps for, or writes the token, and no assertion prints request headers |
| T-01-05-03 | Information disclosure | emitted stylesheet content | low | accept | app.css holds only UI-SPEC design tokens and layout rules — no secrets, no user document content; shipping it to the local browser is the intended behavior |
| T-01-05-04 | Tampering | kernel/webui/build output embedded into the binary | medium | mitigate | The build output stays gitignored and is regenerated from source in Tasks 1–3; the smoke test now verifies the served stylesheet actually carries the app's own `#020617` token rather than trusting that a CSS file merely exists |
| T-01-05-SC | Tampering | npm installs | high | mitigate | No package is added, removed, or upgraded in this plan: package.json and package-lock.json are not in files_modified, and Task 3 deliberately skips `npm ci` in favour of building from the already-installed, lockfile-pinned node_modules audited in 01-01 |
</threat_model>
