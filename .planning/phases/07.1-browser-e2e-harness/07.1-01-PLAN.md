<objective>
Stand up the Playwright harness as one production-quality end-to-end slice: `make e2e` builds the shipped artifact, boots a hermetic kernel from a generated temp config, drives a real Chromium against the embedded SPA, and asserts seeded mock items render in the stream — then broaden the fixture API so every downstream spec plan needs zero fixture edits.

Purpose: prove the whole harness architecture (build ordering, env isolation, ephemeral ports, TOML round-tripping between `smol-toml` and Go's `pelletier/go-toml/v2`, readiness and first-sync gating, teardown) on one thin path before nine spec files are written on top of it. If any of those assumptions is wrong, it is wrong after one commit rather than after six plans.

Output: `web/playwright.config.ts`, the `web/e2e/` fixture and spec tree, a `make e2e` target, and two green specs — the tracer and a hermeticity guard.
</objective>
