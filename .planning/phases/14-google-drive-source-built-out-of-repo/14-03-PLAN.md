<assumption_delta_decision>
**Signal:** `chosen` — the phase success criterion reads "Documents in a **chosen** Drive folder", flagging that a configuration decision may have become a modelling decision.

**Noun now primary:** the configured Drive root folder.

**Decision:** `no-change`.

**Rationale:** a source instance already targets exactly one root and expresses everything else through its match vocabulary — the identical shape Phase 12's filesystem plugin established (D-05). The folder id is an extras string on a source instance, not a modelled entity in the kernel index, whose identity remains (source instance, per-source item id). Promoting "folder" to a first-class kernel noun would require the kernel to know what a folder is, which is precisely the plugin-agnosticism SRC-06 exists to prove. No accepted debt.

**Suggested invariant (optional, for the plugin repo's own suite):** a test asserting that two instances of the plugin configured against two different folder ids produce disjoint item sets under one kernel, encoding "the root is per-instance configuration, not global state".
</assumption_delta_decision>
