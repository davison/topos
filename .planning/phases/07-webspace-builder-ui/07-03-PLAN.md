<objective>
**As a** person with more than one webspace, **I want to** switch between them and create a new one from the header itself, **so that** composing my webspaces happens where I already am rather than in a separate settings screen or a text editor.

Purpose: 07-01 and 07-02 built the write path and the apply seam; this plan puts the first composition surface on top of them and establishes the three overlay primitives (dialog, dropdown-menu, alert-dialog) that every remaining builder surface in 07-04 and 07-05 is built from. It also retires the standalone home page, which D-10 declares redundant once the header owns composition.

Output: the three hand-adapted overlay wrappers, a webspace switcher replacing the static title, a create-webspace modal, a redirect-only root route with a real first-run empty state, and the shared pure config-document edit helpers every later modal reuses.
</objective>
