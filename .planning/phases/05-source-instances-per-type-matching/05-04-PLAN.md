<objective>
Move rendition presentation from the plugins into the kernel (D-11, the folded todo). Today three plugins each carry their own near-identical `themeStyle` constant and `WrapDocument` copy, so a theme change means editing three plugins — and once plugins are third-party, sanitization sits outside the trust boundary entirely. After this plan, plugins return content plus a declared content shape and the kernel sanitizes, wraps and themes it at the one boundary that already owns the rendition CSP.

Purpose: remove the per-plugin duplication and pull the sanitization trust boundary kernel-side ahead of the plugin-ecosystem milestone; this rides Phase 5's contract break so there is one break instead of two.
Output: a kernel-owned rendition module with three content-shape policy profiles, a single kernel-owned stylesheet, and three plugins that no longer own presentation.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| plugin subprocess → kernel content route | rendition bytes are now unsanitized source-controlled content crossing into the kernel |
| kernel content route → browser iframe | the kernel serves source-controlled bytes from its own origin under the rendition CSP |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-15 | Tampering | rendition sanitization gap during the D-11 move | critical | mitigate | The kernel module and its full relocated test suite land in Task 1 before any plugin stops sanitizing in Task 2; there is no shipped state where neither side sanitizes |
| T-05-16 | Tampering | text/html rendition with an unspecified content shape | high | mitigate | The kernel fails closed with `unsupported_content_shape` and writes no body; the enum's zero value is UNSPECIFIED and pinned by the standing contract test |
| T-05-17 | Spoofing | chat message body forging transcript structure | high | mitigate | The producing plugin escapes every interpolated text field before assembly, and the kernel's chat policy allows a class attribute only on div and only within the fixed transcript token set — a crafted body can neither open a bubble nor flip a run's ownership |
| T-05-18 | Information Disclosure | rendition document causing an outbound request | high | mitigate | The composed stylesheet contains no import rule and no url() token, the email and chat profiles hide images, and the unchanged rendition CSP permits no subresource — asserted by the module's own tests |
| T-05-19 | Elevation of Privilege | widened style handling in the email profile | medium | mitigate | The email policy is carried across verbatim, including the case proving an email cannot mark a declaration important, so the kernel inherits proton's proven allowlist rather than a re-derived one |
