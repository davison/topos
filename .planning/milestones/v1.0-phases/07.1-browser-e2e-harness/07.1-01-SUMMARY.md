## Issues Encountered

- Playwright's `test.extend` typing rejected a worker-option tuple whose first generic parameter was `Record<string, never>` (a false structural-typing mismatch) — resolved by using `object` for that generic slot, matching Playwright's own documented pattern.
- Playwright forbids overriding a worker-scoped option (`configSpec`) from inside a nested `describe` block ("Cannot use({ configSpec }) in a describe group, because it forces a new worker") — the originally-sketched isolated-`stop()`-test-in-its-own-describe design does not work; restructured per the key-decisions entry above.
- The acceptance criterion `grep -c 'webServer' web/playwright.config.ts` is 0 caught a doc-comment that used the literal word "webServer" while explaining why the option isn't used — reworded to avoid the literal string.
