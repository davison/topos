### `plugins/mockstrict/main.go` (service, request-response)

**Analog:** `plugins/signal/main.go` (full file read above)

**Imports pattern:**
```go
import (
	"encoding/json"
	"fmt"
	"os"

	goplugin "github.com/hashicorp/go-plugin"

	"github.com/davison/topos/sdk"
)
```

**Required-field fatal-guard core pattern** (mirrors `plugins/signal/main.go`'s `sourceConfig`/`main()`):
```go
type sourceConfig struct {
	Path string `json:"path"`
}

func main() {
	raw := os.Getenv("WEBSPACES_SOURCE_CONFIG")
	if raw == "" {
		fatal(fmt.Errorf("WEBSPACES_SOURCE_CONFIG is not set"))
	}
	var cfg sourceConfig
	if err := json.Unmarshal([]byte(raw), &cfg); err != nil {
		fatal(fmt.Errorf("parse WEBSPACES_SOURCE_CONFIG: %w", err))
	}
	if cfg.Path == "" {
		fatal(fmt.Errorf("WEBSPACES_SOURCE_CONFIG: path is empty"))
	}

	impl := NewSourcePlugin(cfg.Path)

	goplugin.Serve(&goplugin.ServeConfig{
		HandshakeConfig: sdk.Handshake,
		Plugins: map[string]goplugin.Plugin{
			"source": &sdk.SourcePluginGRPCPlugin{Impl: impl},
		},
		GRPCServer: sdk.GRPCServer,
	})
}

func fatal(err error) {
	fmt.Fprintln(os.Stderr, "topos-plugin-mockstrict:", err)
	os.Exit(1)
}
```

**Why `path`, not `base_url`/`token`:** `kernel/config/config.go`'s `Validate` (lines ~326-368) hard-codes exactly two accepted source shapes: `base_url`+`token` OR `path`. D-05/D-06 describe "a required connection field" (singular) with a seeded default — `path` is the only single-field shape the kernel's config validator accepts, so the e2e plugin must copy `plugins/signal`'s shape exactly, not `plugins/paperless`'s two-field shape.

**Naming constraint (hard, code-verified):** the binary must be built as `topos-plugin-<name>` where `<name> != "mock"` — `kernel/pluginhost/discover_binaries.go` filters on `PluginBinaryPrefix = "topos-plugin-"` and excludes the exact literal `"topos-plugin-mock"` (`ExcludedPluginBinaries`). Any other suffix (e.g. `mockstrict`) is discovered and offered in the UI's "+ New <plugin type>…" picker.

### `web/e2e/fixtures/kernel.ts` (fixture, event-driven process lifecycle)

**Analog:** `scripts/dev-guard-smoke.sh` (bash — full file read above; no existing TypeScript analog since Playwright is new to this repo)

**Patterns to port from bash to TS (mechanics, not literal code):**
- **Ephemeral port allocation** — `dev-guard-smoke.sh`'s `free_port()` binds `127.0.0.1:0` via Python, reads the OS-assigned port, closes. TS equivalent: `node:net`'s `createServer().listen(0)` (per RESEARCH.md's Supporting Libraries table).
- **Readiness polling, never `sleep(N)`** — `dev-guard-smoke.sh`'s `run_case`/the `dev` Makefile target's own readiness loop polls `ss -H -tln "sport = :$PORT"` once a second up to a timeout, failing loud on exhaustion (never a vacuous pass). TS equivalent: `fetch`-retry against `GET /api/webspaces` until `200`.
- **Loud, deterministic teardown** — `dev-guard-smoke.sh`'s `cleanup()` trap kills tracked PIDs/process groups explicitly (`kill -- "-$PGID"`) rather than relying on implicit process exit. TS equivalent: track the `ChildProcess` from `spawn()`, call `.kill()` in fixture teardown (`use()` continuation), and `rmSync(tmp, { recursive: true, force: true })` the temp dir.
- **Env-only control surface** — the `dev` Makefile target's `DEV_KERNEL_CMD ?= go run ./cmd/topos serve` line and `dev-guard-smoke.sh`'s `run.sh` heredoc set `XDG_CONFIG_HOME` explicitly and nothing else — mirrors `cmd/topos/main.go`'s no-CLI-flags fact (RESEARCH.md Pitfall 2): the kernel fixture must set `XDG_CONFIG_HOME` in `spawn()`'s `env` and nothing else inherited from the developer's real environment.
- **"Never touch the real port/config" safety pattern** — `dev-guard-smoke.sh`'s `assert_no_real_port_leak()` records a baseline PID on the real dev port (7777) at script start and treats any different PID appearing there later as a critical safety violation. The Playwright fixture's analogous safety net is D-04/Pitfall-1's requirement: always emit absolute `index.path`/`plugins.dir` — never rely on `applyDefaults`.

**Illustrative shape** (from RESEARCH.md Pattern 1 — WebSearch-sourced, MEDIUM confidence, use as starting skeleton not verified code):
```typescript
export const test = base.extend<{ kernel: KernelFixture }>({
  kernel: async ({}, use) => {
    const port = await allocateEphemeralPort();
    const tmp = mkdtempSync(path.join(tmpdir(), 'topos-e2e-'));
    const configDir = path.join(tmp, 'topos');
    const configPath = writeTempConfig(configDir, { port, tmp });
    copyPluginBinaries(tmp);

    const child = spawn(KERNEL_BIN, ['serve'], {
      env: { XDG_CONFIG_HOME: tmp, PATH: process.env.PATH ?? '' }
    });
    await waitForReady(`http://127.0.0.1:${port}/api/webspaces`);
    await use({ baseURL: `http://127.0.0.1:${port}`, configPath });
    child.kill();
    rmSync(tmp, { recursive: true, force: true });
  }
});
```

### `web/e2e/fixtures/config-builder.ts` (utility, transform)

**Analog:** `config.example.toml` (shape/comment reference) + `kernel/config/types.go` struct fields (`ServerConfig.Listen`, `IndexConfig.Path`, `PluginsConfig`, source `base_url`/`token`/`path` fields)

**Core pattern — fields that MUST always be explicit (never left to `applyDefaults`)**, per RESEARCH.md Pitfall 1 (`kernel/config/config.go:157-165 applyDefaults`):
```toml
[server]
listen = "127.0.0.1:<ephemeral-port>"

[index]
path = "<tmp>/index.db"        # ABSOLUTE — default is ~/.local/share/topos/index.db (REAL data)

[plugins]
dir = "<tmp>/plugins"          # ABSOLUTE — default resolves relative to the executable (bin/plugins/, REAL plugin set)
```

Use `smol-toml`'s `stringify()`/`parse()` (per RESEARCH.md Standard Stack) rather than hand-rolled string templating, matching D-04's "parsed TOML, never string matching" requirement on the read side, and avoiding hand-rolled TOML-escaping bugs on the write side.

**Source-block shape constraint** (from `kernel/config/config.go` `Validate`, confirmed lines ~326-368): every `[sources.<id>]` block needs exactly `base_url`+`token` OR `path` — the mockstrict plugin instance's block uses `path` only, matching its Go-side `sourceConfig.Path` field.

### `web/e2e/specs/*.spec.ts` (test, request-response/UI)

**Analog:** `scripts/e2e-smoke.sh` (git history, `git show HEAD~5:scripts/e2e-smoke.sh` — full content read above), being retired but its assertion *shapes* must reappear hermetically per D-09.

**Patterns to port:**
- **Readiness-before-assert discipline** — e2e-smoke.sh never asserts against the server until its own readiness loop (`for i in $(seq 1 30); do curl -fsS ... ; done`) succeeds; same discipline belongs in the Playwright kernel fixture (see `kernel.ts` above), not repeated per spec.
- **Stylesheet assertion** (D-09 explicitly calls this out to reabsorb): e2e-smoke.sh fetches `/`, extracts the `<link rel="stylesheet">` href, fetches that CSS, and hands it to `scripts/assert-stylesheet.sh` to check for the theme token. Playwright equivalent: navigate to `/`, use `page.locator('link[rel="stylesheet"]')` or an API `fetch()` inside the test, assert the response body contains the theme token — do this in `smoke-core-journey.spec.ts`.
- **Stream item-shape assertion**: e2e-smoke.sh's `jq -e '.items | length > 0'` and the `link.fidelity == "exact"` / `link.url startswith $prefix` checks are the shape-check pattern to port into `smoke-core-journey.spec.ts`, replacing paperless-specific fields with the mockstrict/mock fixture's known item corpus.
- **404 envelope assertion** (`.error.code == "webspace_not_found"`) — matches `docs/api.md`'s HTTP envelope; any spec asserting an API error shape should follow this same `{error: {code: ...}}` structure via `expect(await response.json()).toMatchObject({ error: { code: '...' } })`.
- **Fail-loud, no vacuous passes** — e2e-smoke.sh explicitly pre-checks port 7777 is free before starting, "so this script's checks don't pass vacuously against a stale build." Every Playwright spec inherits this from the per-file kernel fixture's own readiness gate; no spec should assume a shared/reused server state.

## Shared Patterns

### Kernel boot mechanics (env-var-only control surface)
**Source:** `cmd/topos/main.go` (`configPath()`), confirmed by RESEARCH.md code reads
**Apply to:** `web/e2e/fixtures/kernel.ts`, every spec file indirectly
`topos serve` takes **no CLI flags** — the only lever is `XDG_CONFIG_HOME`, which determines `$XDG_CONFIG_HOME/topos/config.toml`. Every fixture must set this env var explicitly per spawned process; never pass `--port`/`--config`-style args (they are silently ignored, not rejected).

### Absolute-path isolation (never rely on config defaults)
**Source:** `kernel/config/config.go` `applyDefaults` (lines 157-165)
**Apply to:** `web/e2e/fixtures/config-builder.ts`
`[index].path` and `[plugins].dir` must always be written as absolute, per-run temp paths in every generated fixture config — omitting either silently falls back to the developer's real index DB / real production plugin set (including cgo Signal).

### Fail-loud, no vacuous passes / zero retries
**Source:** `scripts/dev-guard-smoke.sh` header comment ("a vacuous pass burned a session once"), `scripts/e2e-smoke.sh`'s pre-flight port-free check, CONTEXT.md D-15
**Apply to:** every spec + the Playwright config's `retries: 0` + trace/screenshot-on-failure settings
A flaky test is a bug to fix, not a retry to configure around; readiness gates use real endpoint polling, never `sleep(N)`.

### Plugin binary discovery constraints
**Source:** `kernel/pluginhost/discover_binaries.go` (`PluginBinaryPrefix`, `ExcludedPluginBinaries`)
**Apply to:** `plugins/mockstrict/main.go` naming, `Makefile`'s `e2e` target, `web/e2e/fixtures/plugin-binaries.ts`
Binary must be named `topos-plugin-<name>` with `<name> != "mock"` to be discovered and offered in the UI's plugin-type picker.

### Config-effect assertions via real TOML parsing, never string matching
**Source:** CONTEXT.md D-04, RESEARCH.md Pattern 2
**Apply to:** every UAT spec whose pass condition names a file outcome (items 3, 6, and implicitly others)
Use `smol-toml.parse()` on the fixture's `configPath` after a UI action; assert on the parsed object shape, never `expect(fileContents).toContain(...)`.
