## Kernel-under-test shape

| Option | Description | Selected |
|--------|-------------|----------|
| Built binary, embedded SPA | Playwright hits a freshly built `topos serve` binary serving the go:embed'd SPA — the exact shipped artifact | ✓ |
| Kernel + Vite dev server | Vite proxying /api — hot-reload while authoring, but guards the dev path | |
| Both modes, CI uses built | Flag flips between the two; more plumbing | |

**User's choice:** Built binary, embedded SPA

| Option | Description | Selected |
|--------|-------------|----------|
| Fresh kernel per test file | Each spec file boots its own kernel on an ephemeral port with its own temp config + index | ✓ |
| Fresh kernel per individual test | Maximum isolation, slowest | |
| One shared kernel, reset via API | Fastest, but reset depends on the machinery under test | |

**User's choice:** Fresh kernel per test file
