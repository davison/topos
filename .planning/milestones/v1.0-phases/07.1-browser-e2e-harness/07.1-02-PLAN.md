<objective>
Build the hermetic e2e-only source plugin that UAT item 5's two-step "New …" flow is ported onto, and give the SPA's connection-field table the matching row so the blank-required-field guard fires in a browser.

Purpose: UAT item 5 guards a real UI mechanism (pre-fill from a seeded default, clear it, submission blocked with zero network requests, restore, proceed). Running that against the real Signal plugin would drag cgo, SQLCipher and a Signal Desktop database into the suite and make CI impossible. A mock-shaped plugin with one required field reproduces every mechanism the item guards with none of that.

Output: `plugins/mockstrict/` (a new go.work module), a `topos-plugin-mockstrict` row in `web/src/lib/plugin-fields.ts`, the `make e2e` build line, and a spec proving the plugin type is discovered and offered.
</objective>
