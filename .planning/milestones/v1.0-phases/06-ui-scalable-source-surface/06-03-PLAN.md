**`web/src/lib/format.ts`** — add a `--- Stream date markers (UI-11) ---` section with a `DateMarker` interface holding `itemId: string`, `timestampUnix: number` and `topPx: number`, a `MarkerGranularity` union of day, week and month, and an exported `dateMarkers(items: StreamItem[], trackHeightPx: number): DateMarker[]`.

Derivation rules, all pure and all documented in the function's comment:
- Return an empty array when there are fewer than two items, when the track height is not positive, or when every item falls on the same calendar date. A single-date stream has nothing to navigate between, so it renders no markers at all rather than one useless tick.
- A candidate marker is the **first item of each new period**, walking the items in the order the stream already renders them — never re-sorted, because the marker's whole job is to describe the stream's actual order. Compute the period key in UTC, matching the day boundary `formatItemDate` already uses, so markers and row dates can never disagree about which day an item belongs to.
- Position is `(index / items.length) * trackHeightPx`, which maps index-proportionally onto scroll offset because the stream is a non-virtualised list of fixed-height rows.
- Granularity is adaptive. Compute day-period candidates first. If every adjacent pair of computed positions is at least 24 pixels apart, use them. Otherwise recompute at ISO-week periods and test again, then at calendar-month periods. Take the first granularity that satisfies the floor. If even month periods violate it, use month periods and then drop any marker landing within 24 pixels of the last one kept, so the floor holds by construction in the degenerate case rather than being silently abandoned.
- The first candidate is always kept; the floor is only ever evaluated against the previously kept marker.

**`web/src/lib/components/StreamRow.svelte`** — add a `data-item-id` attribute bound to `item.id` on the root button element. Nothing else in this component changes; this is the hook the overlay uses to resolve a scroll target without reaching into the list's internals.

Cover:
- **Empty and singular.** Zero items, one item, and a non-positive track height each return an empty array.
