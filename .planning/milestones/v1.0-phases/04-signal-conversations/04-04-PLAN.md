<objective>
Close G-04-1 (blocker): the Signal contact-form deep link is rejected by Signal Desktop
because `plugins/signal/deeplink.go` percent-encodes the E.164's mandatory leading `+`
as `%2B`, and Signal's shipped validator requires a literal `+`.

Purpose: the phase's success criterion 2 ("detail pane shows the conversation thread with
an 'open in Signal' affordance") is only half true today — the group/bare form works, the
1:1 contact form throws an error modal. This is the phase's one remaining blocker (SRC-02).

Output: a deep-link builder that admits phone numbers by allowlist and emits them verbatim,
a test suite that demands the literal `+` instead of enshrining the mangling, an end-to-end
shape guard in the smoke script, a re-synced live index, and a security register that no
longer claims a mitigation that has been removed.
</objective>
