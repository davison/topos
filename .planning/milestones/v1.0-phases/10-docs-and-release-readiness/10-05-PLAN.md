<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| README → new user's first actions | Whatever the README instructs, a new user runs verbatim on their own machine against their own personal data stores |
| README → user's security expectations | A user's mental model of what topos exposes on the network is formed entirely by what the README says about it |
| Published binary → user's machine | The README's install path tells a user to download and execute a binary from the internet |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-22 | Spoofing | A rewritten README that softens or drops the loopback-only, no-authentication disclosure | high | mitigate | The existing security-boundary paragraph's substance is preserved verbatim in scope: loopback bind, no HTTP API authentication in v1, LAN bind a decision deliberately not made, warn-not-refuse on non-loopback.
