<objective>
Close the phase with the guarantee that cannot be observed from either half
alone: an installed instance and a dev instance running side by side, neither
noticing the other, pinned by a committed gate rather than by memory (ISOL-03);
and the operator-facing documentation that makes the migration onto installed
artifacts a followable procedure (INST-03).

Purpose: this is the whole reason the milestone is one phase. Install is only
proven safe at the moment a dev instance runs beside it without either
noticing, and the roadmap explicitly asks that this guarantee — the kind that
decays silently — be pinned by a committed test rather than left as a
remembered manual check.

Output: `scripts/simultaneity-smoke.sh` and `make isolation-check`, the testing
and contributing docs brought back in step with the six gates this repository
now has, and the install document's migration runbook.
</objective>

  <action>
Create `scripts/simultaneity-smoke.sh` (`set -euo pipefail`), the committed proof for ISOL-03. It must be safe to run on a machine where the operator's real installed instance is already serving, which means it never binds that instance's port and never touches real directories — every path it uses lives under a work directory it creates, with the home and XDG config and data environment variables pointed there for every process it starts, and every listener on an OS-assigned ephemeral port.

Capture the same real-port safety baseline the dev guard smoke captures at start, and re-assert it after every case, so a regression that made this script bind the production port fails as a named safety violation rather than as a quietly successful run.

Build two instances inside the work tree:

- The installed-shaped instance: run the real install script from a fixture release into a temp prefix, then a config at the temp XDG config location with its index and a source store at the temp XDG data location, so the instance is genuinely resolving through home and XDG the way the installed instance does.
- The dev-shaped instance: a checkout-shaped tree with its own config file, its own index, its own plugin directory, and its own source store, all inside that tree. Run the real guard against this config first and require it to pass — a dev-shaped fixture that could not survive the guard would prove nothing.

Then assert three layers, each a named case:

1. **Port contract, statically.** Read the kernel's compiled-in production listen default and the dev recipe's own dev-port default from their source files and assert they are different values. This is the ISOL-02 contract expressed without binding either port, so the assertion holds even on a machine where the operator's instance owns the production port.
2. **Byte-unchanged.** With the installed-shaped instance stopped, take a recursive digest manifest of its whole config-and-state tree. Start only the dev-shaped instance, let it complete a sync and perform a real write of its own (an item mark, or a config save through the API), then stop it and re-take the manifest. Assert byte-identical, failing with the differing path. Because the installed-shaped instance was not running, any difference could only have come from the dev instance.
3. **Concurrent and independent.** Start both instances, each on its own ephemeral port, each seeded with a distinct webspace name. Wait for both to be serving, then assert each answers with only its own webspace set and never the other's. While both are up, capture the sorted file-set of the installed-shaped instance's tree, drive a sync and a write on the dev instance, and assert the file set is unchanged — a stray write from the dev instance would appear as a new path even where the installed instance's own activity legitimately changes an existing file's bytes. Tear both down through the cleanup trap.

Add an `isolation-check` target to the Makefile with the explanatory comment block this file's targets carry, stating what it proves, that it needs no network access, no credentials, and no config file, and that it is safe to run while the operator's own installed instance is serving. Register it in `.PHONY`.

- **ISOL-03 / unclassified** — the probe could not classify this requirement's
  edge category. Planner assumption: "run simultaneously without clashing" is
  proven adequately by two instances with disjoint config, state, and ports

  digest manifest across a dev run. This plan does not attempt to prove absence

  the read-only guarantee the Signal plugin already carries.
