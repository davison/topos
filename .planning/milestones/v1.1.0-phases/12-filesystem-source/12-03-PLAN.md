<objective>
Make the folder a real folder: subfolder recursion as a typed on/off setting threaded from
config through the launch envelope into the walk, a walk that survives the things real trees do
(symlink cycles, permission-denied subtrees, dot directories), health that degrades honestly
when a network mount goes away, and the committed read-only guard every topos plugin carries.

Purpose: this is where criteria 2 and 4 are actually met. The change-detection story is
deliberately structural rather than clever — a full re-walk every Match, returning the complete
current set, with the kernel's existing full-replace persistence doing the removal detection.
Nothing in this design calls an OS filesystem watcher, which is exactly why it works on NFS and
SMB, where `inotify` never fires for another client's writes.

Output: the typed `recursive` config key end to end, `walk.go`, honest health, and
`readonly_test.go`.

Costly decision flagged for the reader: adding `recursive` as a typed `config.Source` field
(rather than a string extras key) publishes a new key in `config.toml` and in the config API's
JSON shape. Undoing it means a config-file migration for anyone who has written it, so it is
worth being right about now — 12-UI-SPEC.md F1 already committed to the typed-boolean shape by
specifying a checkbox rather than a text input.
</objective>

  <action>
  Move the tree traversal out of the tracer's inline `os.ReadDir` into `walk.go`, built on
  `filepath.WalkDir` (never the older `filepath.Walk`). The walk takes the resolved root, the
  recursive flag and the compiled scope, and returns the complete current candidate set plus a
  count of skipped subtrees for logging.

  Policy decisions to implement, all of them 12-CONTEXT.md discretion items being settled here
  and worth stating in the file's own doc comment so a later reader does not have to guess:
  - Recursion off means the root's own directory entries only; on means every depth.
  - A directory entry whose name begins with a dot is not descended into, and a file whose name
    begins with a dot is not a candidate, unless an explicit include_glob pattern matches it.
    This keeps version-control and application metadata directories out of a document folder by
    default without a special-cased name list.
  - A symlinked directory is never descended into. This closes the ancestor-symlink loop and
    prevents an in-tree link from silently widening the folder the operator consented to. A
    symlinked regular file is followed for classification, but its resolved real path must still
    be inside the root before it becomes an item.
  - A per-entry error (most often permission denied on a shared mount with mixed ACLs) skips
    that entry or subtree and continues; it never aborts the walk. An error reading the root
    itself does abort, because that is the mount-is-gone case and must not look like an empty
    folder.
  - Context cancellation aborts with an error. Never return a partial set: the kernel's
    `ReplaceWebspaceSourceItems` treats whatever comes back as the complete truth, so a partial
    set would delete real items.
  - A fixed per-sync item cap (25,000) bounds the response; exceeding it is an error naming the
    cap and pointing the operator at `exclude_glob`, never a silent truncation.

  Extend the folder-label rule for nested files: a file at `receipts/2026/inv.pdf` under a root
  named `docs` carries the labels `receipts`, `2026` and `receipts/2026`, while a file directly
  in the root carries `docs`. This is what lets a webspace match block name either a subfolder
  name or a full relative path, as D-05 describes, with the keywords fallback matching folder
  names the same way.

  Rework `Health` so a readable root is reachable, an empty-but-readable root is still
  reachable, and an unreadable or missing root is unreachable with the OS error as the reported
  cause. Do not implement any persisted last-known-mtime cache anywhere: the freshness bound for
  a network mount is the sync interval, and a cache is a second source of truth that can get
  stuck on a stale attribute.

  Add `web/e2e/specs/12-filesystem-recursion.spec.ts`: a module-scope corpus with a top-level
  document and a nested one, two sources over the same corpus (one recursive, one not) with
  distinct instance ids, and a webspace matching the nested subfolder's name. Assert the

  the nested file, trigger a re-sync through the existing refresh route, and assert the item
  leaves the stream — criterion 2's add/change/remove claim, driven end to end.
  </action>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| source folder → plugin walk | Arbitrary directory structure the operator does not control fully — symlinks, permission-denied subtrees, hostile-by-accident depth |
| operator config → kernel → plugin | A new typed key crossing the config file, the config API and the launch envelope |
| plugin → kernel index | The returned set is treated as the complete truth by full-replace persistence |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-12-12 | Information Disclosure | symlinked directory inside the source root | high | mitigate | Symlinked directories are never descended into; a symlinked regular file's resolved real path is re-validated against the root before it becomes an item, so a link cannot widen the folder the operator consented to expose |
| T-12-13 | Denial of Service | symlink cycle or unbounded tree depth | high | mitigate | Not descending into symlinked directories removes the cycle class entirely; a fixed per-sync item cap bounds the response and fails with a named error rather than truncating |
| T-12-14 | Tampering | plugin writing into the watched folder | high | mitigate | Committed package-local AST guard (Task 3) fails the build on any os-package write selector, with negative-control fixtures proving the scan has teeth (PLUG-02) |
| T-12-15 | Denial of Service | a partial item set persisted by full-replace | high | mitigate | Cancellation and root-read failures return an error rather than a partial set; only a completed walk is ever returned, so the kernel never deletes items because a sync was interrupted |
| T-12-16 | Repudiation | an unreachable mount presenting as an empty folder | medium | mitigate | Health distinguishes readable-and-empty from unreadable, and Match errors rather than returning an empty set for an unreadable root, so the chip shows a named cause instead of the stream silently emptying |
