- **The gap (fresh review CR-01, Critical, blocking).** `plugins/filesystem/fetch.go`'s
  `fetchByKind` derives an item's preview classification from the package-level helper in
  `classify.go`, which consults the fixed `extensionTable` alone. `Match`/`walk` decide the same
  question through `scope.includes`, which implements D-03's documented precedence: a declared
  `include_glob` REPLACES the default extension allowlist, and a file it admits whose extension is
  unrecognized is deliberately classified metadata-only (`scope_test.go`'s
  `TestScope_UnknownExtensionIncludedByGlobIsMetadataOnly` pins that branch). Fetch cannot reach
  that branch, so any item indexed ONLY because `include_glob` widened scope answers
  `codes.NotFound` — surfaced by the kernel as `404 item_not_found` on both
  `GET /api/items/{id}` and `GET /api/items/{id}/content` — for a file that is on disk and that
  the UI itself lists in the stream. The verification pass reproduced this live with
  `include_glob="**/*.zip"` plus an `archive.zip`. The documented, correct answer is D-04's
  metadata-only outcome: `available: false` with `preview not supported for this file type; open
  in source`, exactly what a `.docx` gets today.
- **WR-02 (fresh review, Warning, security hardening).** `resolvePath` and
  `FilesystemOpenHandler` both validate containment against the `filepath.EvalSymlinks`-resolved
  path and then perform the actual read/exec against the original lexical path — validating one
  path and using another. Closed here by reading and exec'ing the resolved path, and by opening
  each fetched file once and reusing that handle for the size check and the read.
- **WR-01 (fresh review, Warning).** `toItem` omits `provenance.source_system`, which
  `docs/plugin-contract.md` documents as plugin-populated and which paperless, silverbullet,
  whatsapp, proton and signal all set. `kernel/httpapi/stream.go` copies provenance verbatim and
  never synthesizes it, so every filesystem item's API response silently drops a documented key.
- **IN-01 (fresh review, Info).** `plugins/filesystem/main.go`'s package doc comment still
  describes the pre-recursion tracer-era state that 12-03 superseded.
