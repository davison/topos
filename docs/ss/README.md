# docs/ss

This directory holds the screenshots the root README embeds. Files are
indexed numerically starting at `1.png` and continuing consecutively.
The root README already references these paths, so dropping a
correctly-named file in here is the only step needed to make an image
appear. No placeholder images are committed, so an index with no file
yet renders as its alt text until the real screenshot lands.

Indices the root README currently references:

- `1.png` — the webspace stream with the detail pane open
- `2.png` — the source chip row with per-source health
- `3.png` — cross-source search results
- `4.png` — the webspace builder UI
